# v0.13.0-rc1

## Summary

Release candidate that finalized CI cancellation hardening and prepared the
0.13 public-alpha train for a full green rehearsal.

The repository did not subsequently cut a final `v0.13.0` tag. The next tagged
release was `v0.13.1`, so `v0.13.0-rc1...v0.13.1` is the correct continuation of
the release lineage.

The GitHub prerelease was published on April 30, 2026 at commit `4e4099cd` and
currently exposes 11 release assets. Other distribution channels have not been
independently reconciled in this audit.

## Highlights

- **CI cancellation cascade fix landed** — label events no longer cancel active
  runs; cancellation now targets pull request synchronize updates only.
- **Version staging alignment** — workspace and feature metadata remain on
  `0.13.0-rc1`, with extension and changelog surfaces aligned for RC publish.
- **Microcrate collapse migration continuity** — includes the migration guidance
  and release-prep groundwork already staged in this train.

## Historical outcome

`v0.13.0-rc1` remained the only `0.13.0` tag. Older references to a later
`v0.13.0` launch describe the intended release train, not a distinct Git tag or
source boundary. The final-version line resumed at `v0.13.1` on May 1, 2026.
