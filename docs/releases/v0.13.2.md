# v0.13.2

## Summary

Public-alpha patch release focused on release-proof cleanup after the `v0.13.1`
channel work. The install paths are the same, but the release train now carries
stronger checks for Homebrew, GNU/musl binary selection, VS Code managed binary
startup, and release-note accuracy.

No Rust API migration from `v0.13.1` is expected.

## Which file should I download?

Most Linux users should choose `gnu`. Use `musl` mainly for Alpine Linux or
musl-based containers. You do not need both GNU and musl archives.

| Your system | Download suffix |
|---|---|
| macOS Apple Silicon | `aarch64-apple-darwin` |
| macOS Intel | `x86_64-apple-darwin` |
| Linux x64 / AMD64, most distributions | `x86_64-unknown-linux-gnu` |
| Linux ARM64, most distributions | `aarch64-unknown-linux-gnu` |
| Linux x64 / AMD64, Alpine or musl containers | `x86_64-unknown-linux-musl` |
| Linux ARM64, Alpine or musl containers | `aarch64-unknown-linux-musl` |
| Windows x64 | `x86_64-pc-windows-msvc` |

## Highlights

- **Install-surface checks** - the release hygiene path now verifies Homebrew
  commands, Cargo package names, binary command examples, GNU/musl release-note
  guidance, and VS Code `linuxLibc` documentation.
- **Homebrew tap proof** - the owned `effortlessmetrics/tap/perllsp` path is
  exercised by public tap smoke coverage, and tap formula generation runs
  through `cargo xtask update-homebrew`.
- **Linux binary selection proof** - installer target-selection tests cover
  GNU/glibc, musl, invalid overrides, the root install wrapper, and Alpine.
- **VS Code managed binary proof** - source and published-package extension
  smokes cover managed binary reinstall, checksum verification, and health
  checks for Marketplace and Open VSX packages.
- **Parser status truth** - parser scorecard status semantics now distinguish
  clean ingestion, salvaged parse rows, and insufficient-data rows consistently.

## Install / upgrade

- **VS Code**: install or update the
  [Perl Language Server](https://marketplace.visualstudio.com/items?itemName=EffortlessMetrics.perl-lsp-rs)
  extension. The managed `perllsp` binary is part of the public-alpha line.
- **Homebrew tap**: install with `brew install effortlessmetrics/tap/perllsp`.
  This uses the owned EffortlessMetrics tap, not Homebrew/core.
- **Package managers**: verify with `perllsp --version` after updating.
- **Source/Binary**: download release assets or use `cargo install perllsp`
  for the published public-alpha package.
