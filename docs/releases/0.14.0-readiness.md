## What we gain

**For users:**
- Completion results are faster — runtime-owned TTL cache (#8514) eliminates redundant prefix module scans across requests.
- Literal `require`/`use` symbols are now tracked and offered in completions (#8623).
- Real-workspace provider baseline (#8637) gives confidence that LSP providers work against real Perl projects, not just test fixtures.
- DAP module-resolution smoke tests (#8621) catch regressions in debug adapter module loading before they ship.

**For contributors:**
- PR sticky CI summary (#8697) and `cargo xtask ci-doctor` (#8693) give clear in-PR feedback without reading raw logs.
- PR title validation (#8700) catches malformed titles before CI, not after.
- Freshness-check xtask (#8683) prevents stale-binary false passes locally.
- PerlOracleEnv v1 (#8675) replaces ambient `$ENV{PERL5LIB}` injection with an explicit typed contract — subprocess environment is now auditable.
- File-policy advisory checker (#8708, #8711) documents non-Rust file ownership with an enforced allowlist, removing a whole class of accidental scope drift.

**For release quality:**
- Clippy temporary-allow burndown (#8712) dropped 4 of 5 workspace-level suppression annotations — only `collapsible_match` remains, tracked in #8561.
- Clippy policy MSRV reconcile (#8707) aligns the clippy lint set with actual Rust 1.95 availability.
- All deferred items have verified-open successor issues — nothing is dropped, everything is tracked.
