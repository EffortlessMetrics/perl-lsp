# v0.17.0

## Summary

Minor public-alpha release. A unified Perl toolchain profile now drives LSP,
DAP, and setup diagnostics; the native formatter discovers and honors project
`.perltidyrc` files; `perllsp --doctor` explains the effective interpreter and
include-path setup; workspace symbols, navigation, rename, completion, inlay
hints, and documentation surfaces gained broader semantic coverage; and the DAP
received a large correctness and protocol-safety pass.

This release also advanced the compiler substrate—HIR bodies, PIR tooling facts,
semantic snapshots, and guarded provider comparison—without claiming a broad
live-provider cutover.

## What improved for users

### One Perl toolchain across analysis, debugging, and setup

- **Shared toolchain profile.** LSP, DAP, and first-run diagnostics resolve Perl
  through one `PerlToolchainProfile`, with perlbrew, plenv, and `PATH` handling
  plus cached version probes for fingerprinted binaries. (#1951, #1978)
- **DAP uses the same default interpreter as the LSP.** When `launch.json` omits
  an explicit `perl`, the debugger uses the shared profile rather than silently
  falling back to a different system Perl. An explicit launch value still wins,
  and unresolved lookup retains the existing actionable PATH error. (#1929)
- **First-run doctor report.** `perllsp --doctor [dir]` prints a read-only setup
  report covering project configuration, interpreter probing, configured roots,
  `PERL5LIB`, system `@INC`, rejected roots, and effective include-root classes.
  Failed probes retain stderr guidance. (#1571, issue #1818)

### Native formatter configuration

- **Automatic `.perltidyrc` discovery.** When no explicit profile is configured,
  the server searches the workspace root, the `PERLTIDY` environment override,
  and `$HOME/.perltidyrc` once during initialization. (#1899, issue #1777)
- **The default native formatter honors the discovered profile.** Supported
  scalar options—line width, indentation, tabs, brace/else placement, keyword
  spacing, and trailing commas—are applied between built-in defaults and
  explicit `.perl-lsp.toml` / `didChangeConfiguration` values. Explicit settings
  remain authoritative. (#2016, #2025, issue #1953)
- **Range formatting is isolated to the selected range.** Complex regex,
  heredoc, `qw(...)`, and POD syntax elsewhere in the file no longer prevents a
  valid selected range from formatting. (#1314)

### Symbols, navigation, signatures, and inlay hints

- **Richer document and workspace symbols.** Package-scoped `our` variables and
  Moo/Moose `has` attributes appear in outlines, workspace symbol search, and
  go-to-symbol. (#1300)
- **Workspace method signature help.** `->method(...)` calls can resolve
  signatures from project symbols and existing signature / `@_` introspection.
  Unknown methods remain quiet. (#1301)
- **Method-call parameter-name inlay hints.** In-file and workspace-resolved OO
  calls can show parameter-name hints after dropping the implicit invocant. The
  provider suppresses unresolved and one-visible-parameter cases to avoid noise.
  (EffortlessMetrics/perl-lsp-swarm#1311)
- **Native `class` and `method` navigation.** Hover and go-to-definition now
  traverse native class/package bodies, resolve method declarations, and find
  class definitions used by calls such as `MyClass->new`.
  (EffortlessMetrics/perl-lsp-swarm#1223)
- **Phase-block hover.** Hovering `BEGIN`, `END`, `INIT`, `CHECK`, or `UNITCHECK`
  explains its compile/runtime timing. (#1298)
- **Cross-package rename promoted.** Safe package rename plans can include
  definition, reference, import-list, and export-list edits. Dynamic boundaries,
  ambiguity, and empty plans still fail closed.
  (EffortlessMetrics/perl-lsp-swarm#1465)
- **Rename coverage and safety.** Rename handles dereference and interpolated
  string occurrences, uses UTF-8-aware word boundaries, and refuses unsafe
  package fallback edits when workspace facts are incomplete. (#1288, #1304,
  #2070)

### Completion and inline completion

- **Framework-aware deterministic inline completion.** Try::Tiny `try`/`catch`,
  Mojolicious::Lite and Dancer routes, and project-indexed package receiver
  methods are offered only with supporting workspace evidence. (#1532, #1573,
  #1585, #1949)
- **Automatic imports on accepted workspace completions.** Eligible unimported
  subroutine, variable, and constant completions can carry an
  `additionalTextEdits` insertion for `use Module;`, extending the existing
  method-completion behavior. (EffortlessMetrics/perl-lsp-swarm#1919)
- **Cleaner completion contexts.** General variable/function/method suggestions
  stay quiet in strings, regex patterns, heredoc bodies, and POD while retaining
  intentional path and quoted module/import contexts. Heredoc detection avoids
  misclassifying arrow-method and constant-shift expressions. (#1808, #1813,
  #1821, #2573)
- **Client matching and insertion metadata.** Completion responses serialize
  `filterText`, advertise PlainText/Snippet insert modes, include inherited
  methods, and keep semantic groups in separate sort tiers. (#1838, #1841,
  #1875, #1889)
- **Qualified-variable replacement edits.** Qualified variable completions now
  send the computed `textEdit`, including UTF-16 position conversion, so strict
  clients replace the typed prefix instead of appending a duplicate qualified
  name. (EffortlessMetrics/perl-lsp-swarm#2603)
- **Multi-root isolation.** Non-module workspace completions are limited to the
  workspace folder owning the current document, preventing symbols from another
  root from leaking into the list. (EffortlessMetrics/perl-lsp-swarm#1217)
- **Parse-safe multiline ghost text.** Multiline inline candidates are checked
  against reconstructed full-document text and fail closed when their ranges
  cannot be applied safely. (#1926)

### Documentation and onboarding

- **VS Code first-run onboarding.** The extension can suggest include paths from
  common Perl module locations, exposes an optional server-gated AI completion
  walkthrough, and ships an openable demo project. (#1898)
- **Clickable POD references.** `L<>` module/core-pragma and same-document section
  references become document links, with validated section fragments. (#1795)
- **Broader and fresher POD surfaces.** Non-standard but common `=head1` sections
  are indexed; cached hover documentation refreshes after external file changes;
  and markdown metacharacters are escaped for literal display. (#1834, #1840,
  #1882)
- **One documentation target resolver.** Hover, document links, resolve, and
  virtual perldoc paths share validated MetaCPAN / `perldoc://` / perldoc.perl.org
  target construction. (#1638)
- **PL701 setup guidance.** Missing-module diagnostics point users to
  `perllsp --doctor` and preserve branch-specific include-path and installation
  guidance. (#2047)

### Editor settings and folding

- **Settings now affect runtime behavior.** `enableSemanticTokens` and
  `enableFormatting` are honored. No-op `enableDiagnostics` and
  `enableRefactoring` settings were removed. (#1290)
- **Nested region folding.** VS Code-style `#region` / `#endregion` markers are
  recognized, including nested and spaced marker forms. Unmatched markers are
  ignored. (EffortlessMetrics/perl-lsp-swarm#1862)
- **Heredoc and multiline folding spans were corrected.** (#1560)

## Debug adapter improvements

### Session, stack, and variables correctness

- **Stale frames are cleared on resume.** A later stop no longer reuses the
  previous call stack. Degraded transport returns an empty result instead of a
  stale historical snapshot. (#1337)
- **No-session `stackTrace` is honest.** It returns an empty frame list rather
  than a fabricated example frame. (EffortlessMetrics/perl-lsp-swarm#1212)
- **Full stack depth survives pagination.** `totalFrames` is captured before
  slicing the requested page. (EffortlessMetrics/perl-lsp-swarm#1237)
- **Large identifiers are bounded safely.** Frame and variable-reference paths
  avoid unchecked `i64` to `i32` truncation and overflow-prone arithmetic.
  (EffortlessMetrics/perl-lsp-swarm#1218)
- **Structured evaluate results expand.** Hashes, arrays, references, and blessed
  objects receive expandable `variablesReference` values. (#1219)
- **Invalid or stale variable references return a safe empty response.** (#1227)
- **Reference spaces are type-separated.** Scope, child, stack, and evaluate
  references use a typed codec rather than overlapping arithmetic bands.
  (#1430, #1444)
- **Pagination metadata is exposed.** Scopes can report `namedVariables` and
  `indexedVariables`; variable responses can report `totalVariables`. (#1810,
  #1811)

### Request and transport behavior

- **Execution-control errors are accurate.** Continue/step requests without a
  session return actionable failures, and `pause` distinguishes no-session from
  signal-delivery failure. (#1240, #1364)
- **Evaluate frame validation.** Invalid, stale, or non-stopped `frameId` values
  no longer silently evaluate in a default scope. Expressions are validated in
  a stable order so users see the relevant error first. (#1496 and
  EffortlessMetrics/perl-lsp-swarm#1246)
- **Protocol ordering is enforced.** `launch` requires `initialize`, and
  `configurationDone` requires an active launch or attach session. (#1806)
- **Capabilities match routed handlers.** Restart-frame, step-in-target, and
  terminate-thread claims follow implemented routes. (#1759)
- **Non-request messages are handled explicitly.** Client Response/Event frames
  do not produce spurious output or disturb request dispatch. (#1790)
- **Persistent event-write failure closes the transport.** The adapter stops
  cleanly rather than silently dropping events or hanging. (#1809)
- **Logpoint interpolation substrate.** Supplied scalar values can be interpolated
  into logpoint message templates; absent or unsupported values preserve the raw
  template. (#1807)

## LSP robustness and protocol corrections

- Bare absolute paths are accepted as file URIs; malformed signatureHelp and
  pre-`didOpen` semantic-token requests return actionable protocol guidance.
  (#1206)
- Multi-root `workspace/symbol` waits briefly for active indexing, records folder
  provenance, and returns deterministic results. (#1522)
- Duplicate parse-complete signals cannot underflow indexing counters into a
  permanent degraded state. (#2606)
- Partial-index reference fallback no longer re-enters the document lock. (#1597)
- Duplicate quick-fix actions are collapsed before building `source.fixAll`, and
  strict/warnings inserts are semantically deduplicated. (#1913, #2058)
- Code actions reject ranges that land inside a UTF-8 code point rather than
  panicking. (#1481)
- Workspace-folder `changeNotifications` now advertises the server's actual
  behavior rather than mirroring an unrelated client capability.
  (EffortlessMetrics/perl-lsp-swarm#1855)
- Content-Length framing uses checked body-offset arithmetic and recovers through
  the invalid-length path on overflow. (#1793)

## Perl parser and diagnostics

- Nested variable lists retain comma-separated nested items. (#1457)
- Negative keyword barewords before `=>` are accepted as strings. (#1460, #1483)
- Custom subroutine attributes and method-shaped content inside interpolated
  strings no longer cause false parser errors. (#1461, #1463)
- `s///e` replacement bodies are classified as executable Perl. (#1238)
- `given` blocks accept ordinary statements and postfix `when` / `default`
  modifiers. (#1893)
- Lexical `my sub`, `our sub`, and `state sub` declarations retain the
  declarator. (#1845)
- `print $hash{key}` and `print $array[index]` are no longer confused with
  indirect-object/filehandle syntax. (EffortlessMetrics/perl-lsp-swarm#1214)
- Recovery after an unclosed delimiter can resynchronize at the following
  statement boundary instead of swallowing later declarations.
  (EffortlessMetrics/perl-lsp-swarm#1456)
- `qw (...)` import lists with whitespace before the delimiter are extracted for
  resolution and dependency indexing. (#1203, #1205, #1292)
- Arrow-deref hash keys stay quiet under strict-bareword diagnostics; missing
  strict/warnings guidance uses Warning severity; valid `%*` and `%.*` printf
  specifiers avoid false positives. (#1562, #1868, #2061)

## Compiler and semantic substrate

The release added or strengthened:

- compiler-derived AST kind inventories and exhaustive NodeKind classification;
- file-scoped semantic IDs and hash-complete file semantic bundles;
- canonical HIR bodies and initial expression/assignment lowering;
- PIR v0 / PIR-A tooling facts and lexical-reference extraction;
- semantic snapshot and PackageSubTable differential rails;
- guarded references shadow comparison and promotion machinery;
- compile-state, parser-boundary, and semantic identity specifications.

These changes improve the foundation for compiler-backed providers. Unless a
feature above explicitly says otherwise, the release did **not** switch a live
LSP provider from the established path to the new compiler substrate.

## Install / package / release path

No intentional change to the install commands. `cargo install perllsp` and
`cargo install perl-dap` remain the expected crate paths, and package-content CI
continues to guard publication.

Channels remain recorded as pending in the repository release ledger. This note
describes the tagged source tree and does not independently assert publication to

## Known limitations

- **Source compare inflation.** `v0.16.0...v0.17.0` includes delayed ancestry
  imported from the 0.16 development cycle. Use the exact
  `git log --first-parent` command in [Release provenance](#release-provenance)
  for logical 0.17 change accounting.
- **Region-folding flake at release sync.** The feature was present, but one
  integration test was quarantined after duplicate folds and a nondeterministic
  region start line were observed. Do not treat the feature as fully stabilized
  until the tracked provider defect is repaired and the test is re-enabled.
- **Proof burndown exceptions.** `ripr-total-burndown` and
  `project-coverage-burndown` remained active; neither allowed new RIPR+ gaps.
- **Compiler cutover boundary.** HIR/PIR and shadow receipts are substrate and
  comparison work, not a blanket live-provider promotion.
