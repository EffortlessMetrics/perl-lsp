# v0.15.2

## Summary

Hotfix release: restores `cargo install perllsp` / `cargo install perl-dap`
functionality that was broken in 0.15.1 due to a missing file in the
published `perl-lsp-rs-core` crate package.

## Highlights

### For users

- **`cargo install perllsp` and `cargo install perl-dap` work again.**
  The `0.15.1` crates.io publish omitted `build_catalog.rs` from the
  `perl-lsp-rs-core` package, causing `cargo install` to fail with a
  missing-file build error. This patch includes the file and adds a CI
  gate to prevent recurrence.

### For contributors

- **Package-content gate for `perl-lsp-rs-core`** — CI now checks the
  `.crate` archive file list, extracts it, and runs `cargo check --locked`
  on the unpacked crate before any publish step. (#9613)

## Release verification

- The [v0.15.2 GitHub Release](https://github.com/EffortlessMetrics/perl-lsp/releases/tag/v0.15.2) is published with
  platform binaries, checksums, SBOM, and VSIX artifact.
- crates.io reports `perllsp`, `perl-dap`, and `perl-lsp-rs-core` at `0.15.2`;
  fresh `cargo install` smokes for `perllsp` and `perl-dap` passed, and the
  installed `perllsp` binary passed the inline-completion stdio smoke.
- VS Code Marketplace and Open VSX report extension version `0.15.2`; both
  published-extension smokes passed after the GitHub Release artifact was
  available.
- Docker publish completed successfully. Docker Hub manifests were verified.
  GHCR public manifest verification returned `denied` with the available token,
  so that boundary remains explicit in the closeout receipt.

## Claim boundary

This release fixes the crates.io install surface only. No user-visible
behavior changes relative to 0.15.1.
