# v0.13.1

## Summary

Public-alpha patch release for release-channel hygiene, naming cleanup, and
package-manager correctness after the `v0.13.0` public alpha.

## Highlights

- **Release channels hardened** - Marketplace, Open VSX, and GitHub VSIX
  reporting stay independent and visible.
- **Homebrew tap aligned** - the owned tap path uses the `perllsp` formula name
  and validates release assets before opening a bump PR.
- **Release naming aligned** - package versions use normal SemVer while the
  product posture remains public alpha.
- **CI Gate diagnostics improved** - release-blocking timeouts are classified as
  gate pressure or hung tests instead of ambiguous runner cancellation.

## Install / upgrade

- **VS Code**: install or update the
  [Perl Language Server](https://marketplace.visualstudio.com/items?itemName=EffortlessMetrics.perl-lsp-rs)
  extension. The managed `perllsp` binary is part of the public-alpha line.
- **Package managers**: install Homebrew with
  `brew install effortlessmetrics/tap/perllsp`; Windows package-manager
  manifests describe public-alpha artifacts. Verify with `perllsp --version`
  after updating.
- **Source/Binary**: download release assets or use `cargo install perllsp`
  only for the published public-alpha line.
