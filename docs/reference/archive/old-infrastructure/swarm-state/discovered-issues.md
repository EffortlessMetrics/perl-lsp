# Discovered Issues

Any agent can append here when they notice something outside their current scope. Scouts read this as an input source alongside their normal focus areas.

Every agent is a passive scout.

## Format

```
### <date> <agent-type>/<branch>
**Category**: <bug-fix | test-gap | docs | devex | infra | security | performance>
**Severity**: <low | medium | high>
**Description**: <what was noticed>
**Context**: <enough detail that a future agent doesn't have to re-investigate>
**Files**: <relevant file paths>
**Suggested branch**: <branch name if obvious>
```
