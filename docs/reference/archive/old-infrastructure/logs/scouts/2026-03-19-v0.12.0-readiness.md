## 9. Ship Recommendation

**Recommendation**: credible for public alpha once the parser-fix wave, version
truth, and ratchet refresh are landed.

The key framing was not “everything is perfect.” It was:
- current shipped truth remains `v0.11.0`
- `v0.12.0` is the hardening milestone
- parser/corpus work is the blocker
- article work is supporting evidence, not a release gate
