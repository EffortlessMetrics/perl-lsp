# Compatibility Donor Agents

This directory holds tracked compatibility and donor material that is **not**
part of the active swarm roster.

Use this material only when you need to inspect an older prompt surface,
recover wording from an earlier swarm generation, or support a compatibility
transition. New docs, prompts, and orchestration should reference the active
tracked roster under [`.claude/agents/`](../agents/README.md) first.
