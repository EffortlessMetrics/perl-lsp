# Agent Catalog (Archived)

Agent definitions have been archived. The orchestrator uses inline prompt
templates and skills instead of loading agent definition files.

See `archive/` for the full historical catalog of 54 agent definitions
(52 agent .md files + 2 JSON roster files).

The original catalog documented:
- 5 core coordinators (scout, builder, reviewer, ops, improver)
- 7 reusable workers (bootstrapper, fixer, validator, pr-responder, research-*)
- 40 specialist workers across implementation, quality, review, explore, scout,
  and docs/devex categories

All files are preserved in `archive/` for reference.

Older agent generations (`agents2` through `agents6` and `agents-compat`) have
been removed from the live repo.
